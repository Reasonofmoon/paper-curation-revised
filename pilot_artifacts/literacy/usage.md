## 키를 넣은 뒤의 대략적 견적

요금은 바뀐다. 실행 직전 [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing)을 확인한다. 아래는 2026년 초 `gemini-2.5-flash` 공개 단가(입력 $0.30 / 1M, 출력 $2.50 / 1M)와 이 저장소 임베딩 스크립트 단가(`gemini-embedding-001` $0.15 / 1M)를 곱한 **상한에 가까운 어림**이다.

- 리뷰 1편: 앞 14,000자 + 효과크기 주변 창 최대 3개. 긴 논문도 한 호출당 입력 약 2만 토큰, 출력 약 1,500 토큰으로 보면 편당 약 $0.01, 22편 약 $0.20.
- 카테고리 요약 6회 + 타임라인 서술 6회: 각 입력 2천–4천, 출력 1천–2천 토큰. 합계 약 $0.05–$0.10.
- 임베딩: 이번 BM25 빌드가 청크 187개, 약 50,896 입력 토큰으로 계산했다. 약 $0.008. 실제 밀집 빌드는 같은 청크를 `gemini-embedding-001`로 보낸다.
- 답변 2개: 발췌 8개 안팎. 합계 $0.02 미만.

합계 어림은 **$0.40 아래**다. 키가 생긴 뒤 `usage_log`가 응답의 `usage_metadata`를 기록하므로, 그 숫자로 이 표를 교체하면 된다.

논문 03은 PDF가 없어 리뷰 대상이 아니다. 22편만 센다.
